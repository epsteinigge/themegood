# Project workflow

The user prefers completed changes to be committed and pushed to GitHub automatically after appropriate checks pass, unless they explicitly request otherwise. Report the pushed branch and commit when finished.

Commit only files and changes belonging to the current task. Preserve unrelated local changes, and do not include secrets, temporary logs, or unrelated personal files. Use a normal push; do not force-push or overwrite remote work.

# Image integrity

Preserve all supplied original images and their content, especially brand logos, certification marks, product packaging, and their text. Do not use AI to regenerate, redraw, blur, or alter supplied images or their content. Use original supplied assets directly and adjust presentation with HTML/CSS. Do not reintroduce generated campaign composites containing altered certification marks or packaging.
